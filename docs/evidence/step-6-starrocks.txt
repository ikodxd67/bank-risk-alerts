## Почему каталог без oracle.temporal.to-datetime: планы Oracle для двух видов литерала
-- с настройкой StarRocks шлёт timestamp
   | Id  | Operation           | Name             | Pstart| Pstop |
   |   0 | SELECT STATEMENT    |                  |       |       |
   |   1 |  PARTITION RANGE ALL|                  |     1 |1048575|
   |*  2 |   TABLE ACCESS FULL | FCT_TRANSACTIONS |     1 |1048575|
      2 - filter(INTERNAL_FUNCTION("TRX_DATE")>=TIMESTAMP' 2026-11-10 
                 00:00:00.000000000' AND INTERNAL_FUNCTION("TRX_DATE")<=TIMESTAMP' 
-- без настройки шлёт date
   | Id  | Operation              | Name             | Pstart| Pstop |
   |   0 | SELECT STATEMENT       |                  |       |       |
   |   1 |  PARTITION RANGE SINGLE|                  |    12 |    12 |
   |*  2 |   TABLE ACCESS FULL    | FCT_TRANSACTIONS |    12 |    12 |
      2 - filter("TRX_DATE"=TO_DATE(' 2026-11-10 00:00:00', 'syyyy-mm-dd
